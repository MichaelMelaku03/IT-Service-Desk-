INC-001

Computer Running Slowly

Performance troubleshooting on a Windows computer.

Windows Task Manager Performance
INVESTIGATION

Task Manager showed 92% memory utilization while CPU and disk utilization were comparatively low. Chrome tabs and background processes were consuming significant memory.

RESULT

Unnecessary tabs and processes were closed. Memory utilization decreased from 92% to 86%.

SKILLS

Performance monitoring, resource analysis, root-cause troubleshooting and technical documentation.

INC-002

Application Won't Open

Simulated software support issue involving Google Chrome.

Software Chrome Processes
INVESTIGATION

Chrome was fully closed, including background processes, and restarted. Its update status was also checked through the About page.

RESULT

Chrome opened successfully after restarting; no underlying application issue was found.

SKILLS

Application troubleshooting, process management, software maintenance and problem diagnosis.

INC-003

Wi-Fi Connectivity Test

Verified end-to-end connectivity on a Windows computer.

Networking ipconfig ping
INVESTIGATION

Confirmed active Wi-Fi, tested multiple websites, reviewed network configuration with ipconfig, verified a default gateway and ran ping google.com from Command Prompt.

RESULT

Successful replies from Google confirmed working internet connectivity end-to-end.

SKILLS

Network troubleshooting, Command Prompt, connectivity diagnostics and technical documentation.

INC-004

Bluetooth Device Connection

Investigated an AirPods discovery issue on Windows.

Bluetooth Hardware Escalation
INVESTIGATION

Bluetooth was enabled, the AirPods were placed in pairing mode, and other nearby Bluetooth devices were detected successfully.

RESULT

The AirPods remained undiscoverable after initial troubleshooting. Next steps included toggling Bluetooth, removing cached pairing data, updating drivers and testing the AirPods on another device.

SKILLS

Peripheral troubleshooting, device discovery diagnostics, Windows settings administration and escalation planning.

INC-005

Website Access Test

Verified whether a Windows laptop could access a live website.

Connectivity Browser Verification
INVESTIGATION

Opened Chrome, navigated to Wikipedia and confirmed the site loaded fully without errors.

RESULT

Website access was successful and connectivity was confirmed end-to-end.

SKILLS

Web connectivity troubleshooting, browser diagnostics, problem verification and technical documentation.

How I approach a support issue

A simple, structured troubleshooting workflow.

01

Understand

Identify the reported issue and establish what is actually happening.

02

Investigate

Use available system, application or network diagnostics to isolate the cause.

03

Verify

Apply a troubleshooting step and test whether the reported issue is resolved.

04

Document

Record findings, results and next steps clearly for future reference or escalation.
